# Бот выдачи файлов по реф-ссылкам

Telegram-бот на Python (aiogram 3). Админ создаёт ссылки с файлами (до 3 штук), пользователь
переходит по ссылке, подписывается на каналы и получает файлы **как есть** (без архивов) с эффектом конфетти 🎉.

## Запуск

1. Python 3.10+.
2. Установи зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Создай рядом с `main.py` файл `.env` (образец — `.env.example`):
   ```
   BOT_TOKEN=токен_от_BotFather
   ADMIN_IDS=157680917
   ```
   На хостинге вместо файла можно задать переменные окружения `BOT_TOKEN` и `ADMIN_IDS`.
4. Запусти:
   ```bash
   python main.py
   ```

### Бесплатные хостинги

* Запуск — просто `python main.py`, вебхуки не нужны (работает через long polling).
* Если хостинг требует слушать порт (Render, Koyeb и т.п.) — он сам задаёт `PORT`, бот поднимет
  на нём страницу `OK` для health-check.
* Бесплатный PythonAnywhere: добавь в `.env` строку `PROXY=http://proxy.server:3128`.
* База — файл `bot.db` (SQLite). На хостингах со «стираемым» диском ссылки и каналы пропадут
  после перезапуска — выбирай хостинг с постоянным диском или задай `DB_PATH` на постоянный том.

## Первая настройка

1. Напиши боту `/start` с аккаунта админа — откроется админ-панель (или `/admin`).
2. **Каналы.** Две ссылки (`https://t.me/+Dt2WoRNTqVUwZGNk` и `https://t.me/+MAObpyzeymlhMmJk`)
   уже добавлены со статусом ⏳. Чтобы бот начал проверять подписку, добавь бота **админом**
   в каждый канал с правом «Пригласительные ссылки» (без него бот не видит заявки).
   Бот сам пришлёт сообщение и спросит, к какой ссылке привязать канал.
   Пока канал не привязан, кнопка пользователям не показывается.
3. **Ссылки.** «📎 Создать ссылку» → отправь до 3 файлов → «Готово». Бот выдаст ссылку вида
   `https://t.me/<бот>?start=<код>`. Файлы `.exe`, `.apk` и т.п. отправляй как документ.

## Как это работает для пользователя

* `/start <код>` → сообщение с просьбой подписаться (жирный текст, премиум-эмодзи, кнопки
  «Подписаться» в один ряд и «Проверить подписку» снизу). Показываются только каналы,
  на которые человек ещё не подписан.
* Каналы по заявкам: достаточно подать заявку — бот засчитывает её как подписку.
* После успешной проверки сообщение удаляется, приходят файлы с эффектом конфетти.
* Повторный `/start` без кода выдаёт файлы последней ссылки, по которой человек переходил.

## Премиум-эмодзи

Бот использует премиум-эмодзи в тексте и на кнопках (`icon_custom_emoji_id`) — это работает,
если у владельца бота есть Telegram Premium. Если Telegram их отклонит, бот автоматически
отправит сообщение с обычными эмодзи, чтобы ничего не сломалось.
ID эмодзи и все тексты лежат в `texts.py`.
